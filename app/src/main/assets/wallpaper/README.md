# Launcher wallpapers

Each of the 14 photos has a full-size JPEG (`<id>.jpg`), a thumbnail (`<id>-thumb.jpg`) and a small blurred
panel backdrop (`<id>-panel.jpg`) used for the frosted glass.

`SOURCES.json` lists every photo's photographer and original page. `catalog.js` holds the per-photo readability
settings and the credit shown in Settings > About; it is generated from `SOURCES.json` and the photos by
`tools/gen_catalog.py`.
