# Launcher wallpapers

Each of the fifteen photos has a full-size JPEG (`<id>.jpg`), a thumbnail (`<id>-thumb.jpg`) and a small blurred
panel backdrop (`<id>-panel.jpg`) used for the frosted glass.

`SOURCES.json` lists every photo's photographer and original page (all from Unsplash). Derived images keep the source
photograph's terms. `catalog.js` holds the per-photo readability settings and is generated by `tools/gen_catalog.py`.
